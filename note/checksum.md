# Checksum command on linux


| Command | Algorithm / purpose | Example |
|---|---|---|
| `sha256sum` | SHA-256 checksum; recommended for file verification | `sha256sum filename` |
| `sha512sum` | SHA-512 checksum; stronger than SHA-256 | `sha512sum filename` |
| `md5sum` | MD5 checksum; legacy and not secure for cryptographic verification | `md5sum filename` |
| `sha1sum` | SHA-1 checksum; legacy | `sha1sum filename` |
| `cksum` | POSIX CRC checksum for basic integrity checks | `cksum filename` |
